# Neural Data Viewer - Next.js App

A modern React/TypeScript implementation of the neural data visualization tool using Next.js and Tailwind CSS.

## Features

- Real-time neural activity visualization
- WebSocket connectivity for live data streaming
- Magma colormap for enhanced visualization
- Responsive design with dark theme
- FPS monitoring and performance tracking

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Learn More

This project uses:

- [Next.js](https://nextjs.org/) - React framework
- [TypeScript](https://www.typescriptlang.org/) - Type safety
- [Tailwind CSS](https://tailwindcss.com/) - Styling
- WebSocket API - Real-time data streaming

## Architecture

The app is structured as follows:

- `src/app/` - Next.js app directory with layout and page components
- `src/components/` - Reusable React components
- `src/lib/` - Utility functions and helpers

The main visualization logic has been converted from vanilla JavaScript to TypeScript React components while maintaining the same functionality and appearance.
